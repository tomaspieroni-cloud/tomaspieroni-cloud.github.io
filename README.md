# Portfolio profesional de Tomás Nelio Pieroni

Sociólogo y Data Analyst. Ciencia de datos aplicada a problemas sociales y organizacionales.

Sitio construido con Quarto y publicado en GitHub Pages: https://tomaspieroni-cloud.github.io/

## Estructura

- `index.qmd`, `proyectos.qmd`, `about.qmd`, `experiencia.qmd`, `publicaciones.qmd`, `contacto.qmd`: páginas principales.
- `proyectos/`: páginas de caso.
- `styles.css`: diseño completo del sitio.
- `fonts/`: Fraunces, Manrope e IBM Plex Mono autoalojadas (licencia SIL Open Font License).
- `images/`: visuales por proyecto, con nombres descriptivos.
- `files/`: CV e informes descargables.

## Flujo de trabajo

```
quarto preview          # revisar en local
quarto publish gh-pages # publicar
```
